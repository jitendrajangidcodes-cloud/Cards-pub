# Cards — public releases

Public releases-only repo for the **Cards** Android app (`com.pnsjy.cards`).

This repo holds only signed release APKs published via GitHub Releases. It has
no source code. It exists so the in-app update checker and the app-store
listing page can read `https://api.github.com/repos/jitendrajangidcodes-cloud/Cards-pub/releases/latest`
without any authentication token. The app source lives in a separate private repo.
