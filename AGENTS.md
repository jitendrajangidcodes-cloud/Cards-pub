## Working in this repo

- This is a **releases-only public mirror** — no source, no keystore, no docs beyond release
  notes. Never add source code, build config, or anything not meant to be public.
- Releases here are published by `Cards-private`'s `scripts/release.sh` — don't cut a release
  independently from this repo; there's nothing here to build.
